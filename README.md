# 🧠 Interactive Neural Network Learning Demo

A college-ready interactive demonstration of neural-network learning using the **XOR problem**.

## What this project demonstrates

This is a real neural network, not a static webpage or fake prediction interface.

The user can change:

- Number of hidden layers
- Neurons per hidden layer
- Activation function
- Learning rate
- Number of training epochs
- Random seed

After training, the application shows:

- The network architecture
- Final training loss
- Training accuracy
- Loss vs. epoch learning curve
- Learned 2D decision boundary
- Predictions and probabilities for all XOR examples

## Why XOR?

XOR is a classic example of a pattern that cannot be separated by a single linear decision boundary. It is small enough to understand visually while still demonstrating why a neural network needs hidden layers and non-linear activation functions.

## Run locally

### 1. Install Python

Use Python 3.10, 3.11, or 3.12.

### 2. Open a terminal in this project folder

```bash
cd interactive_nn_learning_demo
```

### 3. Create a virtual environment (recommended)

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Start the app

```bash
streamlit run app.py
```

Streamlit will open the demo in your browser.

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, `README.md`, and `.gitignore`.
3. Go to Streamlit Community Cloud.
4. Sign in with GitHub.
5. Choose **Create app**.
6. Select your repository and branch.
7. Set the main file to:

```text
app.py
```

8. Deploy.

The application uses only files in the repository and does not require a database, API key, model download, secret, or local file path.

## Suggested 5-minute demonstration

**0:00–0:40 — Introduction**

Explain that the demo shows a neural network learning the XOR pattern.

**0:40–1:20 — Dataset**

Show the four XOR examples and explain that the target is 0 when both inputs are equal and 1 when they are different.

**1:20–2:10 — Network settings**

Show the controls:
- hidden layers
- neurons
- activation
- learning rate
- epochs

**2:10–3:00 — First training run**

Click **Train Neural Network** and explain:
- loss curve
- training accuracy
- learned decision boundary

**3:00–4:10 — Interaction**

Change one or two settings, such as:
- 1 hidden layer → 2 hidden layers
- fewer neurons → more neurons
- different activation function
- lower/higher learning rate

Retrain and point out how the learning curve and boundary change.

**4:10–5:00 — Conclusion**

Explain that the network learns by updating its weights during training, and that hidden layers plus non-linear activation allow it to learn the non-linear XOR relationship.

## Important

The output is generated by an actual `sklearn.neural_network.MLPClassifier` trained inside the application. The charts and predictions are calculated from that trained model.
